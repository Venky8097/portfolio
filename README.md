# Venkatesh Tadiparthi — Portfolio

A responsive, static personal portfolio based on the supplied two-page resume. No build tools are required.

## Contents
- `index.html`: complete CV website, including education, skills, projects, internships, certifications, extracurricular activities and contact details.
- `style.css`, `script.js`: styling, animations, navigation.
- `assets/Venkatesh_Tadiparthi_Resume.pdf`: original uploaded CV, accessible through the Download CV links.
- `.github/workflows/deploy.yml`: automated GitHub Pages deployment.

## Publish on GitHub Pages
1. Create a **public** GitHub repository, for example `portfolio`.
2. Upload the **contents** of this folder to your repository's `main` branch (including the hidden `.github` directory).
3. Open **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Under **Actions**, check the `Deploy to GitHub Pages` workflow run.
5. Visit `https://YOUR_USERNAME.github.io/portfolio/` after deployment.

For a user-site URL `https://YOUR_USERNAME.github.io/`, name the repository `YOUR_USERNAME.github.io`.

## Customize
Edit `index.html` to update text, projects, and links. The source resume supplied no GitHub username, project repositories, project technical implementation details, or headshot; these have **not** been invented. Add your own links and expanded project descriptions when available.

The downloadable PDF retains your contact information from the uploaded resume. Use a public repository only if you're comfortable making those details public.
